# Changelog

## 1.0.6
- 스마트폰 앱 로그인 또는 토큰 만료 시 발생하는 "ID 또는 패스워드를 확인하세요" 세션 불일치 무한 루프 버그 수정
- 만료/무효화된 토큰 감지 시 저장된 ID/비밀번호로 자동 재로그인 및 신규 세션 갱신 복구 로직 추가
- 애드온 기동 시 기존 세션 유효성 자동 검증 및 무효 세션 즉시 정리

## 1.0.5
- 난방 및 에어컨 제어 명령 수신 버그 수정 (MQTT `mode_set`, `temp_set` 토픽 구독 추가)
- 난방/에어컨 설정 온도 변경 시 동작 모드 및 온도 상태 즉시 동기화
- 난방 켜기 시 설정 희망온도 일괄 전달

## 1.0.4
- HaCasa Nova 카드 v3.1.0 번들 내장 및 한글 slug 방 이름 패치 지원
- 기기 및 엔티티 한글 친화적 명칭 매핑 개선

## 1.0.0
- Home Assistant MQTT Discovery 지원 (조명, 대기전력 콘센트, 난방, 에어컨, 환기, 일괄스위치, 엘리베이터 호출 버튼)
- Ingress 사이드바 대시보드 지원 (실시간 기기 토글, 온도 조절, 실시간 이벤트 로그)
- 세션 자동 저장 및 복구 (/data/.hiot-session.json)
